# 画質向上ツール（ローカル版）

PDF・画像をブラウザにドラッグ&ドロップするだけで高画質化するツールです。
**処理はすべて自分のPCの中で行われ、ファイルが外部に送信されることはありません。**

Next.js本体（アンプレ）とは独立したツールで、本体のビルド・実行には影響しません。

---

## 使い方（Mac）

### 準備（初回のみ）

1. Python 3.10以上が必要です。ターミナルで `python3 --version` と入力し、バージョンを確認してください。
   - 入っていない・古い場合は https://www.python.org/downloads/macos/ からインストールしてください。
2. このフォルダ（`tools/image-enhancer`）をMacに置きます。

### 起動

- Finderで `start.command` をダブルクリックします。
  - 初回だけ、必要なライブラリのインストールで数分かかります（インターネット接続が必要です）。
  - 「開発元を確認できないため開けません」と表示されたら、右クリック →「開く」を選んでください。
    うまくいかない場合は、ターミナルで `bash start.command` を実行してください。
- ブラウザで `http://127.0.0.1:8765/` が自動で開きます。
- 終了するときは、ターミナルのウィンドウで `Control + C` を押します。

### 操作

1. 左の「設定」で補正方式などを選ぶ（通常はそのままでOK）
2. PDF・画像をドロップ（複数可）
3. 「比較を見る」で補正前後を見比べる（ドラッグで境目を移動、「等倍で見る」で細部を確認）
4. 「ダウンロード」または「すべてダウンロード（ZIP）」で保存

出力ファイル名は `元の名前_高画質.pdf`（画像は `元の名前_高画質.png`）です。

## 要件

| 項目 | 内容 |
|---|---|
| 目的 | 低解像度のPDF（スクリーンショットを印刷したものなど）や画像を、印刷・拡大表示に耐える画質にする |
| 実行環境 | Mac（Windows・Linuxでも `python app.py` で動作） |
| プライバシー | 処理はPC内で完結。サーバーは `127.0.0.1` のみで待ち受け、他のPCからはアクセスできない |
| 入力 | PDF / PNG / JPEG / WebP / BMP / TIFF、複数ファイル同時 |
| 出力 | PDF → PDF（ページサイズ・レイアウトそのまま）、画像 → PNG、まとめてZIP |
| 操作 | ブラウザ画面でドラッグ&ドロップ、補正前後の比較表示 |

## 機能設計

### 補正方式

| 方式 | 処理内容 | 向いているもの | 速度の目安※ |
|---|---|---|---|
| **高速補正**（既定） | ノイズ除去 → Lanczos拡大 → アンシャープマスク → レベル補正 | 教科書・プリントなど文字が中心の資料 | 1ページ 1〜2秒 |
| **AI超解像** | Real-ESRGAN（realesr-general-x4v3）で細部を推定して描き足し、通常拡大と「AIの強さ」の割合で混ぜる | 写真・イラスト・図版 | 1ページ 5〜10秒 |

※ 1000×600px程度の画像を3倍にした場合

> **注意**：AI超解像は、元の画像にない線を推定して描き足します。小さな漢字では字形が変わることがあるため（例：「種」が別の字に見える）、文字が中心の資料には高速補正をおすすめします。AIを使うときは「AIの強さ」を下げると、元の字形に近くなります。

### 設定項目

| 項目 | 既定値 | 説明 |
|---|---|---|
| 拡大倍率 | 3倍 | 2〜4倍。出力の長辺が10,000pxを超える場合は自動で倍率を下げる |
| AIの強さ | 60% | AI超解像のときだけ表示。AIの出力と通常の拡大結果を混ぜる割合 |
| シャープさ | 1.0（AIは0.5） | 輪郭を強調する強さ（0〜2） |
| ノイズ除去 | 弱 | JPEG圧縮によるブロックノイズなどを、拡大前に取り除く |
| 白を白く・黒を黒く | ON | 明るさの分布の両端を切り詰め、紙の白と文字の黒をはっきりさせる |

### PDFの扱い

- ページ全体を画像化するのではなく、**PDFの中に埋め込まれた画像だけ**を高画質化して差し替えます。
  - PDF内の文字データ（ベクター文字）や図形は劣化させずにそのまま残ります。
  - 同じ画像を複数ページで使っている場合は、1回だけ処理します。
  - 一辺48px未満の小さな画像（アイコンなど）は対象外です。
- 画像を含まないPDF（文字だけのPDF）は、もともと拡大に強い形式なので変更しません。
- パスワード付きPDFには対応していません。

### 構成

```
tools/image-enhancer/
├── start.command          … Mac用の起動スクリプト（初回は .venv に自動セットアップ）
├── app.py                 … ローカルWebサーバー（Flask）
├── enhancer/
│   ├── filters.py         … 補正処理（高速補正・AI超解像）
│   └── documents.py       … PDF・画像の読み書き、プレビュー作成
├── templates/index.html   … 画面
├── static/                … 画面のCSS・JavaScript
├── models/                … AIモデル（ONNX形式）とライセンス
└── scripts/convert_model.py … AIモデルをPyTorch形式からONNX形式に変換したスクリプト（参考）
```

- ブラウザからファイルを受け取ると、ジョブとして順番に1件ずつ処理します（CPUを使い切る処理のため）。画面は進捗を定期的に確認します。
- 処理結果はメモリ上にだけ保持され、ツールを終了すると消えます（直近50件まで）。

## コマンドで起動する場合

```bash
cd tools/image-enhancer
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py              # --port 9000 でポート変更、--no-browser でブラウザを開かない
```
